# 項番20（TanStack Query）繰り上げ時の注意点（対応済み）

1. `queryKey` は `view/favorite` 単位で分離する（例: `["posts", view, favorite]`）。
2. スケルトンは「初回データなし」のときだけ表示する。
3. 再取得中は既存リストを保持する（`isFetching` 中に一覧を空にしない）。

# 項番21（hasEdits離脱確認）UX改善メモ

1. 現在の戻る/進む時の離脱確認は「クエリ変化検知 → 保留 → `router.replace` で巻き戻し」のため、画面が一瞬ちらつく。
2. 項番21の要件（クエリベース保留→確定後適用）は満たしているが、見た目の品質改善余地がある。
3. 改善方針:
   - `searchParams` は遷移検知用に寄せる。
   - 画面表示と一覧取得は「確定済みクエリ（effective/committed query）」を参照する。
   - 保留中は遷移先UIを描画しない。
4. 仕様追記は最小でよい:
   - 「保留中は遷移先UIを一瞬でも表示しない（ちらつかせない）」をUX要件として追記。
