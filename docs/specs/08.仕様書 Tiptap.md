
- タイトル（H1）
- ノート投稿
	- 制約の正本:
		- 保存可否（許可ノード/許可マーク/属性制約）は `docs/specs/12.仕様書 投稿編集-本文形式.md` を正とする
		- 本書はエディタUI（操作方法・見た目・表示方針）のみを扱う
	- 保存/表示の責務分離:
		- 保存時の正データは TipTap JSON（`content`）とし、`contentText` はサーバー側で `content` から導出する
		- 一覧表示のノート本文は `content` から HTML へ変換し、サニタイズして描画する
	- ツールバーで設定できる:
	    - 見出し（H2/H3/H4）
	    - リスト（箇条書き/番号付き）
	    - 引用
	    - 太字
	    - リンク（選択範囲に setLink、解除 unsetLink）
	- md記法で設定できる:
	    - # / ##（見出し）
	    - - / 1. （リスト）
	    - >（引用）
	    - **text**（太字）
		- 保存可否の最終判定は `docs/specs/12.仕様書 投稿編集-本文形式.md` の許可集合に従う
	- 見た目をmd風に変える:
	    - .tiptap h1/h2, .tiptap ul/ol, .tiptap strong, .tiptap a をCSS定義
	    - 一覧表示側（PostCard）でもノート本文に同系統スタイルを適用
	- SSR/ハイドレーション方針（PostCard）:
	    - 初回SSRではノート本文HTMLを空で描画し、ハイドレーション完了後にサニタイズ済みHTMLを描画する
	    - 目的は SSR/CSR のサニタイズ結果差による hydration mismatch 回避
	    - サニタイズ済みHTMLを描画できない場合は `contentText` をプレーン表示し、`contentText` も使えない場合は fail-closed（空文字）とする
