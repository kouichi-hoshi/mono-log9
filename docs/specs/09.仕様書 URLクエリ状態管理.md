# 概要

ログイン中画面の表示状態を URL クエリで一元管理し、以下を実現する。

- モード切替・ごみ箱表示・お気に入り絞り込み状態を URL から復元できる
- ブラウザの戻る/進むで状態が再現される
- 既存クエリ（例: `stubAuth`）を破壊しない

---

# クエリパラメータ仕様

対象画面: ログイン中画面（`AuthedScreen`）

| パラメータ          | 値                           | デフォルト  | 用途             |
| -------------- | --------------------------- | ------ | -------------- |
| `view`         | `memo` \| `note` \| `trash` | `memo` | 表示中の画面状態       |
| `favoriteMemo` | パラメータ有り/無し                  | 無し     | お気に入り絞り込み（メモ）  |
| `favoriteNote` | パラメータ有り/無し                  | 無し     | お気に入り絞り込み（ノート） |

- 実URLでは `?favoriteMemo` または `?favoriteMemo=` のどちらも「有り」とみなす。
- `favoriteMemo` / `favoriteNote` は有無で判定し、未指定は OFF とみなす
- favorite はモード別で持つ

## 状態遷移表

| 現在状態（クエリ）                 | 操作        | 遷移後状態（クエリ）                | 備考                                         |
| ------------------------- | --------- | ------------------------- | ------------------------------------------ |
| `?view=memo`              | 「メモ」押下    | 変更なし                      | no-op（URL更新なし）                             |
| `?view=memo`              | 「ノート」押下   | `?view=note`              | `favoriteMemo/favoriteNote` は保持            |
| `?view=memo`              | 「ごみ箱」押下   | `?view=trash`             | `favoriteMemo/favoriteNote` は保持して非参照       |
| `?view=memo`              | 「お気に入り」押下 | `?view=memo&favoriteMemo` | `favoriteMemo` を付与（ON）。`favoriteNote` は保持  |
| `?view=memo&favoriteMemo` | 「お気に入り」押下 | `?view=memo`              | `favoriteMemo` を削除（OFF）。`favoriteNote` は保持 |
| `?view=note`              | 「メモ」押下    | `?view=memo`              | `favoriteMemo/favoriteNote` は保持            |
| `?view=note`              | 「ノート」押下   | 変更なし                      | no-op（URL更新なし）                             |
| `?view=note`              | 「ごみ箱」押下   | `?view=trash`             | `favoriteMemo/favoriteNote` は保持して非参照       |
| `?view=note`              | 「お気に入り」押下 | `?view=note&favoriteNote` | `favoriteNote` を付与（ON）。`favoriteMemo` は保持  |
| `?view=note&favoriteNote` | 「お気に入り」押下 | `?view=note`              | `favoriteNote` を削除（OFF）。`favoriteMemo` は保持 |
| `?view=trash`             | 「メモ」押下    | `?view=memo`              | `favoriteMemo/favoriteNote` は保持            |
| `?view=trash`             | 「ノート」押下   | `?view=note`              | `favoriteMemo/favoriteNote` は保持            |
| `?view=trash`             | 「ごみ箱」押下   | 変更なし                      | no-op（URL更新なし）                             |

## クエリ保持ルール

- `view/favoriteMemo/favoriteNote` を更新するとき、他クエリは保持する
	- 例: `stubAuth=1` は失わない
- 未知のクエリキーも削除しない
- `view` が不正値・未知値・欠落の場合は `memo` へフォールバックする
- 同一キーの重複は正規化し、1キー分の有無として扱う

補正後の例:

- `/?stubAuth=1`
  → `/?stubAuth=1&view=memo`
- `/?stubAuth=1&view=xxx&favoriteMemo&favoriteMemo`
  → `/?stubAuth=1&view=memo&favoriteMemo`

## 履歴ルール

- ユーザー操作による状態変更は履歴を積む（戻る/進む可能）
- 初期正規化（不足/不正の補正）は履歴を汚さない方法で行う
- URLが実質変化しない操作は履歴を増やさない
