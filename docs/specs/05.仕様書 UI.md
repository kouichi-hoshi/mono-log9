# html構造

以下の階層構造を持つ

- 未ログイン
	- header
	- main
		- article（ウェルカムメッセージ）
	- footer

- ログイン済み
	- header
		- 「ノートを書く」ボタン（ユーザーアイコン左、押下でフルスクリーンモーダル）
		- section
			- モード別エディタエリア
				- mode=memo: メモエディタ
				- mode=note: モーダル内にノートエディタを配置して非表示
	- main
		- article
			- メモ・ノート一覧
	- footer（display:none;）
