# html構造

以下の階層構造を持つ

- 未ログイン
	- header
		- サービスロゴを表示
	- main
		- article（ウェルカムメッセージ）
	- footer

- ログイン済み
	- header
		- サービスロゴを非表示
		- モード切り替えとユーザーロゴを表示
	- main
	- footer（display:none;）

# レイアウト

- miroで作成したワイヤーフレームを参照する
- レスポンシブデザインを採用する。
