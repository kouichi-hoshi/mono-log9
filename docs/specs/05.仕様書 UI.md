# html構造

以下の階層構造を持つ

- 未ログイン
	- header
	- main
		- article（ウェルカムメッセージ）
	- footer

- ログイン済み
	- header（display:none;）
	- main
		- article（miroのコンテナ1を参照）
		- article（miroのコンテナ2を参照）
	- footer（display:none;）

# レイアウト

- miroで作成したワイヤーフレームを参照する
- レスポンシブデザインを採用する。
	- ブレイクポイントはmd（Tailwind準拠）

|       | デフォルト                         | md以上        |
| ----- | ----------------------------- | ----------- |
| カラム数  | 1                             | 2           |
| コンテナ1 | 下部に固定する、常時表示する                | 固定する、常時表示する |
| コンテナ2 | スクロールする、下部にコンテナ1を表示するスペースを設ける | スクロールする     |
