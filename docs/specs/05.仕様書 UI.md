# レイアウト

- miroで作成したワイヤーフレームを参照する
- レスポンシブデザインを採用する。
	- ブレイクポイントはmd（Tailwind準拠）

|      | デフォルト | md以上 |
| ---- | ----- | ---- |
| カラム数 | 1     | 2    |

## html構造

以下の階層構造を持つ

- 未ログイン
	- header
	- main
		- article（ウェルカムメッセージ）
	- footer

- ログイン済み
	- header
	- main
		- article（コンテナ1）
		- article（コンテナ2）
	- aside
	- footer
- ログインした後は、headerとfooterは非表示にする
