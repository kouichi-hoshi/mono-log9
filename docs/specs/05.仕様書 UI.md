# html構造

以下の階層構造を持つ

- 未ログイン
	- header
	- main
		- article（ウェルカムメッセージ）
	- footer

- ログイン済み
	- header
	- section
		- タブパネル
			- メモエディタ or ノートエディタ
	- main
		- article
			- メモ・ノート一覧
	- footer（display:none;）

# レイアウト

- miroで作成したワイヤーフレームを参照する
- レスポンシブデザインを採用する。
