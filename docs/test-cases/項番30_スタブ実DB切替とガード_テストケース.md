# 項番30 テストケース

## 対象

- `isStubAuthMisconfigured()` の真偽判定
- Auth Route Handler（`/api/auth/[...nextauth]`）の誤設定時 403 + JSON 契約、handlers 委譲しない検証
- authAdapter 相当入口（`auth.ts`）の誤設定時 FORBIDDEN 契約
- 誤設定検知時のログ出力
- `USE_STUB_POSTS` の切替・ガード（項番30スコープ。回帰検証は本表 + 既存テスト参照で充足）

## 非対象

- Auth.js の通常認証フロー詳細（項番26 に委譲）

## USE_STUB_POSTS のトレーサビリティ

項番30は `USE_STUB_AUTH` / `USE_STUB_POSTS` 両方の切替・ガードを対象とする。`USE_STUB_POSTS` は以下で充足:
- 本表: TC-013〜TC-015（最低限の回帰ケースを本ファイルで明示的に検証）
- 既存: `lib/__tests__/env.test.ts`（getStubPostsEnabled の test/production 無効化）、`lib/posts/__tests__/stubPostRepository.test.ts`（"rejects access outside development" で ensureDevelopmentOnly を検証）

**方針**: 本ファイルで明示的に再検証（TC-013〜TC-015）を行い、既存テストとのトレーサビリティを追記する形で項番30完了判定を可能にする。
