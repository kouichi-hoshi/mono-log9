# 項番27-B テストケース

## 対象

- 投稿一覧ソートロジックの共通化（通常: `createdAt DESC, id DESC` / ごみ箱: `trashedAt DESC, id DESC`）
- `PostRecord` のソート用内部キー（`createdAtEpochMs` / `trashedAtEpochMs`）
- Stub/DB Repository 返却値へのソート用キー付与
- 投稿追加直後と再取得後（リロード相当）での並び一致

## 非対象

- cursor 契約そのものの変更（`v1` 仕様追加・変更）
- DB スキーマ変更（項番27で実施済み）
- 認証・認可仕様の追加変更
