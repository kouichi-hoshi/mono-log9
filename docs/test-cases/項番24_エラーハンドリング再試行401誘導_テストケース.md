# 項番24 テストケース

## 対象

- 401 時のログイン誘導（トースト + 入力維持 + ログインモーダル自動表示）
- 403/404 時の状態維持とエラー通知
- 500/予期しないエラー時の通知と再試行導線
- 初回取得/追加取得/更新系操作の失敗時 UI 挙動
- エラー文言/アクション文言の整合（`docs/specs/06`）

## 非対象

- Auth.js 本実装（項番26）
- 権限制御のサーバー実装詳細（項番29）
- ごみ箱一括削除フロー自体（項番23）

| ID | レベル(Unit\|結合\|E2E) | 観点 | 前提 | 手順 | 期待結果 | 実績(Pass/Fail) | メモ | 証跡 |
|---|---|---|---|---|---|---|---|---|
| TC-001 | Unit | 401 のエラー分類 | エラー分類関数を単体呼び出し可能 | `code=UNAUTHORIZED` または 401 相当エラーを入力する | 「ログインが必要です」扱いとして分類される |  |  |  |
| TC-002 | Unit | 403/404 のエラー分類 | 同上 | 403 と 404 を入力する | それぞれ「権限がありません」「対象が見つかりません」で分類される |  |  |  |
| TC-003 | Unit | 500/予期しないエラー分類 | 同上 | 500 と未知エラーを入力する | 「サーバーエラーが発生しました」または「エラーが発生しました」で分類される |  |  |  |
| TC-004 | Unit | 再試行可能判定 | 再試行可否判定関数を単体呼び出し可能 | 初回取得失敗/追加取得失敗/更新系失敗を入力する | 再試行導線の要否が仕様どおり判定される |  |  |  |
