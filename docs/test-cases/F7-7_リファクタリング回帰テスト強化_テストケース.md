# F7-7 テストケース

## 対象

- F7-3〜F7-6で分割した hook/lib/UI 境界の回帰検知強化
- 主要導線（編集、戻る/進む、favorite、ごみ箱操作、再試行）の自動検知
- Jest（Unit/結合）と Playwright UI の回帰実行セット固定

## 非対象

- 本番機能仕様の追加・変更
- DBマイグレーション、DBデータ更新、環境変数運用変更
- 実認証フローのE2E拡張（F7-7では対象外）

## 完了判定（F7-7）

- 本ファイルの必須TC（TC-F77-001〜TC-F77-007）が実装済みかつ Pass
- 分割対象 hook の境界分岐（pending action / IO監視抑止）が自動検知可能
- 再試行導線（初回一覧取得失敗→再試行成功）の Playwright UI テストが追加されている
- 既存主要5spec（has-edits / note-composer-history / favorite-filter / trash-delete / infinite-scroll）との回帰セットが通過している

## 実行コマンド

`mono-log9-app` ディレクトリで実行:

```bash
pnpm exec jest components/authed/__tests__/useGuardedQueryNavigation.test.ts components/authed/__tests__/useInfiniteLoadMore.test.ts components/authed/__tests__/AuthedScreen.test.tsx --runInBand
pnpm exec playwright test e2e/has-edits.spec.ts e2e/note-composer-history.spec.ts e2e/favorite-filter.spec.ts e2e/trash-delete.spec.ts e2e/infinite-scroll.spec.ts e2e/retry.spec.ts
```
