# 項番23 テストケース

## 対象

- ごみ箱画面での一括選択 UI（表示中の投稿を選択/選択解除/件数表示）
- 選択投稿の完全削除と「ごみ箱を空にする（全件削除）」
- 削除確認モーダル文言と操作分岐（キャンセル/削除）
- 削除失敗時の状態維持と再試行導線
- `view=trash` 出入り時の選択状態リセット

## 非対象

- 投稿のごみ箱投入/復元（項番19）
- ノートモーダル履歴連動（項番22-A）
- 認証エラー時のログイン誘導（項番24）
