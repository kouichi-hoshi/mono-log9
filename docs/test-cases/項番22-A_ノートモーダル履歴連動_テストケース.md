# 項番22-A テストケース

## 対象

- ノートモーダル状態の URL クエリ管理（`noteComposer=create` / `noteComposer=edit:<postId>`）
- ノートモーダル開閉時の履歴制御（開くと履歴を1件積む、閉じると `noteComposer` を除去）
- 戻る/進む時のモーダル状態遷移（モーダル状態を先に変化）
- hasEdits あり時の保留遷移と「破棄して続行/編集を続ける」分岐
- `noteComposer` 正規化（不正値は未指定へ補正）と他クエリ保持

## 非対象

- ノート本文の保存形式・バリデーション（項番17/18）
- favorite 絞り込み仕様の妥当性（項番22）
- ごみ箱一括削除（項番23）
