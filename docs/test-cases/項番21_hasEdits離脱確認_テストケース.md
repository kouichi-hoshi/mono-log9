# 項番21 テストケース

## 対象

- `hasEdits` 判定（編集開始基準との比較、保存成功後の基準更新、破棄確定時のリセット）
- 離脱トリガー時の確認ダイアログ表示制御（キャンセル/Esc/URL変更/他投稿編集開始/戻る進む）
- 離脱確認ダイアログの分岐（「破棄して続行」/「編集を続ける」）
- URL変更操作（モード切替/お気に入り絞り込み/ごみ箱切替）に対する継続・破棄時の遷移可否

## 非対象

- favorite 絞り込みの取得結果自体の正当性（項番22で検証）
- ノートモーダル履歴連動（戻る/進む時にモーダル状態のみ先に変化させる挙動、項番22-Aで検証）
- ごみ箱の一括削除処理（項番23）
