# ワイヤーフレーム運用（Miro）

## 目的/スコープ
- Miroのワイヤーフレームを一次情報源としてUI実装を進めるための運用ルールをまとめる
- 対象: UI実装に必要な要件整理/要約

## Miroフレーム指定方法
- 指定はフレーム名（タイトル）で行う
- 1実装 = 1フレームを原則とする
- 例外（複数フレームで1画面など）がある場合は、対象フレーム名を列挙して指示する

## エージェントが出力すべき要約項目
- 画面の目的/主要導線
- UI要素一覧（入力/ボタン/テーブル/モーダル等）
- 文言（ラベル/エラーメッセージ/ヘルプ/プレースホルダー）
- 状態（空/読み込み/エラー/権限なし等）
- コンポーネント分割案（shadcn/ui再利用前提）
- 不明点/確認事項

## 注意
- Miroの内容が最優先。曖昧な箇所は「不明点」として列挙してから実装する
