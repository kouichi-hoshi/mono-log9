# CWV計測チェック表

`docs/specs/仕様書 CWV計測.md` に従い、手動計測の結果と課題を記録する。

## 目標値

| 指標 | 目標値 |
|------|--------|
| LCP | ≤ 2.5s |
| CLS | ≤ 0.1 |
| INP | ≤ 200ms |

※ p75 で判定

|--------|--------|---------|-----|-----|-----|------|----------------|------------|
| | | | | | | | | |
| | | | | | | | | |

### 記入ガイド

- **計測日**: 計測を実施した日（YYYY-MM-DD）
- **ツール**: PageSpeed Insights / Vercel Speed Insights
- **対象URL**: 計測したページのURL
- **LCP / CLS / INP**: 計測値（単位は LCP: s、INP: ms）
- **達成**: ◎＝全項目達成 / △＝一部未達 / ×＝未達
- **課題・改善メモ**: 未達の場合、未達項目・仮説・改善方針を記入
- **再計測予定**: 改善後の再計測予定日（YYYY-MM-DD、なければ空欄）
