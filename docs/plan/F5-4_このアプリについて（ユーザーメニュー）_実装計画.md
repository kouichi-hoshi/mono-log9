## 技術メモ

### next.config.ts での version 注入

```ts
import type { NextConfig } from "next";
import { readFileSync } from "fs";
import { join } from "path";

const packageJson = JSON.parse(
  readFileSync(join(process.cwd(), "package.json"), "utf-8")
) as { version?: string };

const nextConfig: NextConfig = {
  distDir: process.env.NEXT_DIST_DIR ?? ".next",
  env: {
    NEXT_PUBLIC_APP_VERSION: packageJson.version ?? "0.0.0",
  },
};

export default nextConfig;
```

- `NEXT_PUBLIC_` プレフィックスによりクライアントから `process.env.NEXT_PUBLIC_APP_VERSION` で参照可能
- `docs/specs/仕様書 環境変数 env.md` への追記は任意（ビルド時注入のため env ファイルには不要）

### AboutAppDialog の props 案

```ts
type AboutAppDialogProps = {
```
