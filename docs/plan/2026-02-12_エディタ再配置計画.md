## ログイン中画面エディタ再配置 + 汎用フルスクリーンモーダル導入計画

### 概要
タブパネルを廃止し、`viewMode` ごとにエディタ表示を固定化する。あわせて、再利用可能な汎用フルスクリーンモーダルを導入し、ノートモーダルの「閉じる時の確認・クリア条件」を仕様化する。

### 実装方針（決定済み）
1. `mode=memo`
- 切替ボタンなし
- 初期表示は `mode=memo`
- メモエディタのみ表示

2. `mode=note`
- 切替ボタンなし
- 「ノートを書く」ボタンを表示
- 押下でフルスクリーンモーダル起動

### 汎用モーダル仕様（新規）
**新規コンポーネント**: `/Users/kouichi/project/my_project/mono-log/mono-log9/mono-log9-app/components/ui/FullscreenModal.tsx`

**責務**
- フルスクリーン `Dialog` 表示
- ヘッダ（タイトル + 閉じるボタン）
- `open/onOpenChange` による開閉制御
- 本文領域に `children` を描画

**想定Props**
- `open: boolean`
- `onOpenChange: (open: boolean) => void`
- `title: string`
- `children: React.ReactNode`
- `onRequestClose?: () => void`  
  - 閉じる要求時のフック（確認アラートなどを親で実装）

### ノートモーダルの開閉・クリア仕様（決定済み）
1. 閉じる操作（ヘッダ閉じる、Esc、背景クリック）はすべて「閉じる要求」として同一処理に入る  
2. ノート入力が空（trim後0文字）なら即時クローズ  
3. ノート入力が1文字以上なら確認アラートを表示  
4. アラートで「破棄して閉じる」選択時のみクローズし、入力をクリア  
5. 「編集を続ける」選択時はクローズせず、入力保持  
6. 保存成功時は入力クリア（既存方針維持）

### コンポーネント責務整理
1. `HeaderPostArea`
- `viewMode` 出し分け
- `noteDraft` と `isNoteModalOpen` を管理
- `onRequestClose` 内で確認アラート分岐を実装

2. `PostEditor`
- 編集UI専任（入力、保存、未入力Alert）
- モーダル開閉責務は持たない
- `expanded/onExpandedChange` は削除（拡大/戻すは廃止）

3. `AuthedScreen`
- `composeTab` state を削除
- `HeaderPostArea` へ `viewMode` のみ渡す

### テスト/確認観点
1. `npm run lint` が通ること  
2. `mode=memo`: メモのみ表示  
3. `mode=note`: 「ノートを書く」のみ表示、押下でモーダル起動  
4. 入力空で閉じる: 確認なしで閉じる  
5. 入力ありで閉じる: 確認表示  
6. 「破棄して閉じる」: 閉じて入力クリア  
7. 「編集を続ける」: モーダル維持・入力保持
